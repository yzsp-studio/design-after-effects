## 🇨🇳 中文

在真实的 After Effects 里制作或续改动效、合成与片头，输入可以是设计素材、视频参考，也可以是已有的 AEP 工程。流程先确认意图、目标与输入，检查 AE 连接与素材是否就绪，再把设计意图落实成可编辑的结构——图层、合成与动效保留可接续的工程形态。默认交付可理解、可继续修改的 AEP，并把渲染预览回传画布。只有明确要求使用 AE 或编辑其工程时才适用；只说「AE 感」或只要一段视频不触发该流程。安装技能本身不附带应用连接或系统权限；AE 不可用时会说明缺口，而不是用生成视频、网页动画或扁平视频工程顶替。

### ✨ 能做什么

- 设计素材 / 视频参考 / 已有 AEP → 可编辑 AEP 工程
- 承接新建、局部修改、参考重建、素材合成与多版本衍生
- 设计意图落成图层与合成的可编辑结构，不交死板成片
- 渲染预览回传画布，工程可继续接手修改
- 动手前确认 AE 连接与素材就绪，交付前验证视觉、运动与工程结构
- 不为「AE 感」或纯视频需求开流程

## 🇬🇧 English

Produces or extends motion graphics, composites and title sequences inside a real After Effects, starting from design assets, video references or an existing AEP. It confirms intent, targets and inputs, checks that the AE connection and source assets are ready, then translates design intent into an editable structure — layers, comps and animation that can be picked up and continued. The default deliverable is an understandable AEP plus a rendered preview returned to the canvas. It applies only when using AE or editing its project is explicitly required; an 'AE look' alone or a plain video request does not qualify. Installing the skill grants no app connection or system permissions, and when AE is unavailable it states the gap rather than substituting a generated video, a web animation or a flattened video project.

### ✨ What it does

- Design assets, video references or an existing AEP in; an editable AEP out
- Handles new builds, local edits, reference rebuilds, asset compositing and variants
- Turns design intent into editable layers and comps instead of a flat video
- Rendered preview returned to the canvas while the project stays reworkable
- Confirms AE connection and asset readiness, then verifies visuals, motion and structure before delivery
- Does not open the flow for an 'AE look' or a plain video request
